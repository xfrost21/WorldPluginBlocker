# 🤝 Contributing to WorldPluginBlocker

We are delighted that you are interested in contributing to WorldPluginBlocker! These guidelines will help us maintain code quality and clear communication.

## 🐛 Reporting Bugs

Before submitting a new bug, please check if it has already been reported in the Issues section.

1.  Use the **Issues** section on GitHub.
2.  Use the **'Bug Report'** template.
3.  Provide as much detail as possible:
    * WorldPluginBlocker and Paper/Spigot version.
    * Steps to reproduce the bug.
    * Full console stack trace (if a console error occurs).

## ✨ Suggesting Features (Feature Requests)

If you have an idea for improving the plugin:

1.  Use the **Issues** section and select the **'Feature Request'** template.
2.  Clearly explain the goal and benefit of your proposed feature.

## 🧑‍💻 Code Contributions (Pull Requests)

If you wish to make changes to the code:

1.  **Fork** the repository.
2.  Create a new branch for your changes (`git checkout -b feature/your-feature-name` or `fix/your-fix-name`).
3.  Ensure your code adheres to the existing code style.
4.  Comment on the problems your code solves or the features it adds.
5.  Create a **Pull Request (PR)** targeting the **`main`** branch.

### Pull Request Requirements

* Ensure the plugin compiles without errors.
* Do not include `.jar` or other compiled assets.
* If the PR fixes a bug, reference the relevant Issue (e.g., `Fixes #123`).
